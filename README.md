## 🌌 What is This Repository?

</div>

> **"Deep Learning is the closest thing we have to magic — and this repo is your spellbook."**

This is my **personal deep learning knowledge hub** — everything I've studied, built, and learned, organized in one place. Whether you're starting from scratch or leveling up to transformers and diffusion models, this repo has you covered.

📦 **What's inside:**
- 📝 Handcrafted notes for every topic
- 💻 Clean, runnable Jupyter notebooks
- 🧪 Hands-on projects with full code
- 📚 Curated resources, papers & videos
- 🗺️ A complete learning roadmap

## ⚙️ Setup & Installation

</div>

```bash
# 1. Clone the repository
git clone https://github.com/milansharma/deep-learning-mastery.git
cd deep-learning-mastery

# 2. Create virtual environment
python -m venv dl-env
source dl-env/bin/activate        # Linux/Mac
# dl-env\Scripts\activate         # Windows

# 3. Install dependencies
pip install -r requirements.txt

# 4. Launch Jupyter
jupyter notebook
```

**requirements.txt includes:**
```
torch torchvision torchaudio
tensorflow keras
transformers datasets accelerate
numpy pandas matplotlib seaborn
scikit-learn opencv-python
jupyter notebook ipywidgets
```

> 💡 **GPU recommended** — Most notebooks run on CPU but will be significantly faster on NVIDIA GPU with CUDA.
